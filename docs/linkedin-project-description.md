# LinkedIn Project Description

## Project Name

Linux SRE Observability and Automation Lab

## Short Description

Built a hands-on Linux SRE lab to demonstrate infrastructure monitoring, alerting, automation, troubleshooting, and incident response workflows.

## Full Description

Designed and built a Linux SRE observability and automation lab using Docker Compose, Prometheus, Grafana, Alertmanager, Node Exporter, Ansible, shell scripting, and OpenSSL.

The project includes Linux health-check scripts, disk usage troubleshooting, TLS certificate validation, kernel semaphore validation, Prometheus alert rules, Grafana dashboard provisioning, Ansible baseline checks, incident runbooks, and RCA templates.

This project simulates common production support and SRE workflows such as monitoring Linux infrastructure, validating system health, investigating capacity issues, documenting incidents, and preparing repeatable operational checks.
