# Contributing

This is a personal learning and portfolio project. Contributions are welcome if they improve Linux SRE, observability, automation, monitoring, or incident response examples.

## Guidelines

- Keep examples generic.
- Do not add company internal data, hostnames, customer names, logs, ticket IDs, or private infrastructure details.
- Prefer clear scripts and documentation over complex abstractions.
- Validate YAML, JSON, and shell syntax before submitting changes.
