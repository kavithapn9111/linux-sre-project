# Linux SRE Project

## Overview
End-to-end SRE project using AWS, Jenkins, Prometheus.

## Components
- AWS EC2 (Ubuntu)
- Jenkins (CI/CD)
- Prometheus + Node Exporter (Monitoring)
- Python app deployment

## Features
- Automated deployment using Jenkins
- Infrastructure monitoring using Prometheus
- Linux server management

## How to Run
1. Setup EC2
2. Install Jenkins
3. Run Prometheus
4. Deploy using Jenkins pipeline
